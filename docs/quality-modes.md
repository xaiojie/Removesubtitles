# 去字幕质量分档建议

普通网页和 PHP API 提供 Lite · 快速、Pro · 标准、Max · 增加三档，默认选 Pro。调用方提交视频和选区，后台按档位选择检测方式、背景修复和复查范围。两个入口共用同一份档位配置、同一个任务 ID 和同一条队列。独立 VSR 程序另有原生入口。[API 接口文档](../php/README.md)

| 档位 | 处理方案 | 适用素材与取舍 |
| --- | --- | --- |
| Lite · 快速 | PP-OCRv5 Mobile 在字幕带内每 8 帧采样，变化处补检。字框外扩 9 px，保留 60 px 背景，合并字形与底板遮罩，GPU LaMa 按批修复。 | 常规横排字幕、批量预览。支持纯字幕任务。 |
| Pro · 标准（默认） | CLEAR 5 步，自动推理分辨率、较大上下文，每块 33 帧、重叠 4 帧，LoRA 强度 1.15。遇到粗描边或底板时先用 LaMa 补背景。 | 多处字幕、字幕和水印混合处理。有水印时，在字幕处理完成后调用 ProPainter。 |
| Max · 增加 | CLEAR 7 步，结合相邻帧对齐与 LaMa 预填，其余字幕参数与 Pro 相同。水印首遍完成后，逐帧筛查原水印选区，对可疑片段局部精修。 | 运动背景、粗描边和带底板字幕。高档的额外耗时和实际改善按样片分别记录。 |

测试分支以 `php/product_modes.json` 为两端共用的档位定义。上述数值是本轮 L20 冻结验收用的配置。独立样片按来源分组，选区、剪辑边界及复核帧见[样片清单](../benchmarks/corpus/README.md)。

## 实测依据

| 对比表记录 | 可用于判断什么 |
| --- | --- |
| VSR-01 | RTX 5050 Laptop 上，5 段竖屏素材共 76.4 秒，LaMa 整批耗时 196.162 秒，折合每分钟素材用时 2 分 34 秒。741 个抽检帧中 OCR 命中 0 次，视频 5 的绳索轻微软化。这个结果来自裁带逐句实验脚本，不能直接当作原生 LaMa 网页的速度。 |
| A100-01、A100-02 | 同一段一分钟字幕加水印素材，A100 80 GB 上，快速裁剪研究版耗时 7 分 22 秒，较大上下文研究版耗时 10 分 42 秒。后者字幕背景衔接更好，仍有局部模糊。Pro 首遍使用的 `balanced` 预设沿用较大上下文思路；部署版本的耗时需单独测量。 |
| A100-03 至 06 | 两段各一分钟的难片，12 步精修后抽查到的字迹、双语底板更干净，部分衣物和手部还有重建痕迹。两次**追加修复**各用 16 分 26 秒、18 分 15 秒。这些记录不能给出Max 档的完整耗时。 |
